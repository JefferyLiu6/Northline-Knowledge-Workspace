New data points beyond the point limit will be rejected, and the web configuration page will prompt "Number of data points exceeds the current model limit" ## 5. Data Collection and Reporting Mechanism Collection tasks are organized by "Collection Groups." A collection group includes several data points, a collection cycle, and a reporting strategy. The minimum collection cycle is 100ms, maximum 3600s. Reporting strategies include three types: **Periodic Reporting**: Pack the latest value and report it at fixed intervals, independent of the collection cycle configuration. Suitable for trend data, such as temperature, current. **Change Reporting**: Report only when the value changes beyond the set deadband threshold. Suitable for state data, significantly reducing traffic. Deadband threshold supports absolute value and percentage formats. **Hybrid Reporting**: Immediately report upon change, while also reporting once at a longer heartbeat cycle to ensure the upper system receives the latest value even if it missed the change event. Recommended for production environments. Data is stored in local cache when the network is down. GTE-3000 has a cache capacity of 100,000 entries, GTE-3000S has 500,000, and GTE-3000Pro has 5,000,000. After network recovery, data is resent in chronological order, with a default transmission rate limit of 200 entries per second to avoid overwhelming the upper system. When the cache is full, the oldest data is discarded on a first-in-first-out basis. ## 6. Edge Computing GTE-3000Pro supports running edge rules and lightweight models on the device

The upgrade process takes about 3 to 5 minutes, during which data collection is interrupted. After upgrade, the device automatically restarts and restores the original configuration ## 9. Typical Deployment Methods **Single Machine Deployment**: One GTE-3000 connects to a PLC and instruments on a production line, and connects to the workshop switch via LAN2, with data reporting to the plant-level MES. **Dual Machine Hot Standby**: Two GTE-3000S units are interconnected via a heartbeat line. The standby unit takes over within 5 seconds if the main unit fails. Point configuration is automatically synchronized from the main unit to the standby unit. Hot standby requires both devices to have the same model and firmware version. **Cascade Deployment**: At the workshop level, multiple GTE-3000 units collect data nearby, and the data is aggregated to a GTE-3000Pro for edge computing and unified cloud upload, reducing the number of public network connections. ## 10. Selection Recommendations - Less than 500 points, with wired network, no edge computing needs: GTE-3000 - 500 to 3000 points, no network cables on site, requires 4G uplink: GTE-3000S - More than 3000 points, requires edge inference or CNC device connection: GTE-3000Pro The point configuration format of all three devices is fully compatible. When upgrading from GTE-3000 to GTE-3000Pro later, export the configuration and import it directly, without needing to re-enter the points.

LAN2 is default as business port, with factory configuration as DHCP client. LAN3 and LAN4 of GTE-3000S and GTE-3000Pro can be configured as switch ports, cascading downstream devices When the management port IP is forgotten, hold the RESET button for more than 10 seconds to restore factory settings, returning the management port IP to 192.168.1.10. Restoring factory settings will clear all collected point configurations; make sure to export the configuration file before operation. ### 3.3 Serial Ports RS485 uses a 2-pin terminal with A and B lines. Serial port parameters support 1200 ~ 115200bps, default 9600bps, 8 data bits, 1 stop bit, no parity check. A maximum of 32 slave devices can be connected on the same 485 bus, with 120Ω terminal resistors required at both ends of the bus. GTE-3000S and GTE-3000Pro have built-in terminal resistors that can be enabled via a dip switch. ### 3.4 Digital Input/Output GTE-3000Pro provides 4 routes DI and 2 paths DO. DI is inputted for dry interfaces, which are relay output, contact capacity 30VDC/2A. DO is often used to connect sound alarms and to export signals when collecting breaks or threshold limits
